# 健診札博打 強さチェッカー

ZIPを展開し、index.htmlをブラウザで開いてください。計算は端末内で行い、入力値を送信・保存しません。

## 入力と結果

7項目すべてを入力します。血圧は健診・医療機関で測定した上・下の両方が必要です。中性脂肪は10時間以上絶食した空腹時の値が対象です。
BMI・尿酸・白血球数（10³/µL）は小数第1位まで、その他は整数で入力します。白血球数の単位を変えても100/µL刻みで判定します。端数の丸め、欠測の補完は行いません。
計算後、札を押すと項目の解説が開きます。解説末尾の「結果へ戻る」で強さ一覧に戻ります。

## 算定仕様

2026年度のワークスペース既存16段階表を使用します。rules.js が全閾値と出典、boundary-tests.csv が境界前後の期待値と実測結果です。中性脂肪の500 mg/dLはD1、1000 mg/dLはD5です。BMIは既存の配点を維持しています。強さはゲーム用の配点です。

## S3・CloudFrontへの配置

ZIPを解凍し、index.html、CSS、JS、assets/ を同じ階層構成で配置します。CloudFrontのディストリビューション直下に置く場合はデフォルトルートオブジェクトに index.html を指定します。ビルドは不要です。
